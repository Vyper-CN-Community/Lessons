**(Slide 2 - Pure vs View)**
[翻页]
大家在写函数的时候，经常会纠结：我是不是该加个装饰器？
[点击显示]
我们先复习一下 **`@view`**。
它的意思是“只读”。比如你想查一下现在的余额，或者查一下某个变量的值。
你只看不改，不消耗链上的存储空间，所以在链下调用它是**免费的**。
[点击显示]
那 **`@pure`** 呢？它比 `@view` 还要“纯洁”。
它连链上的状态都不看。它就是一个纯粹的计算器。
比如你写个函数 `add(a, b)`，返回 `a + b`。这个计算结果只跟输入有关，跟链上谁有才发了多少币完全没关系。
这时候就用 `@pure`。这不仅是语义清晰，编译器还能帮你做优化。

**(Slide 3 - 控制流：If / Else)**
[翻页]
接下来是**控制流**。
智能合约不是傻瓜执行，它需要判断。
[点击显示]
Vyper 的 `if...else` 写法跟 Python 一模一样。
比如这个例子：
如果 `x < 10`，返回 "Small"；
如果 `x < 100`，返回 "Medium"；
否则，返回 "Large"。
[点击显示]
要注意的是，在区块链上写逻辑，**越简单越好**。
虽然 Vyper 支持这些判断，但如果你写了十八层嵌套的 if/else，Gas 费可能会爆炸。
保持逻辑扁平，既省钱又安全。
