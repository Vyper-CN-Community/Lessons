**(Slide 5 - 连接 Remix 与 Tenderly)**
[翻页]
怎么用呢？很简单。
[点击显示]
1. 去 Tenderly 官网开个 Virtual Testnet。
2. 把它给你的 RPC 地址填进 MetaMask。
3. 在 Remix 里选 "Injected Provider - MetaMask"。
搞定！你现在就在一个**私人豪华包间**里开发了，既有主网的真实环境，又没有主网的高昂费用。

**(Slide 6 - 第二部分：EVM 与 ZKSync)**
[翻页]
接下来聊点硬核的：我们的代码到底跑在哪？

**(Slide 7 - 什么是 EVM?)**
[翻页]
Vyper 代码编译后，会变成字节码，运行在 **EVM (以太坊虚拟机)** 上。
EVM 就是一套标准规则。
[点击显示]
好消息是，现在很多链都支持这套规则，比如 Arbitrum, Optimism, Polygon。
只要是 **EVM 兼容**的链，你的 Vyper 合约理论上都能跑。

**(Slide 8 - ZKSync 与 Remix)**
[翻页]
这时候有同学问了：那 ZKSync 呢？可以部署吗？
[点击显示]
**注意！** 这是一个大坑。
虽然 ZKSync 很火，也是 EVM 兼容的。但是！
**Remix 自带的 ZKSync 插件目前不支持 Vyper！** 它只支持 Solidity。
[点击显示]
所以，如果你想把 Vyper 部署到 ZKSync，光靠 Remix 是不行的。
我们需要更高级的本地开发工具，比如 **Moccasin** 或者 **Titanoboa**。
别急，这些大杀器我们后面的课程会专门教。今天先知道这个限制就好。

**(Slide 10 - If / Elif / Else)**
[翻页]
编程怎么能没有 `if` 呢？
Vyper 的 `if` 语法跟 Python **一模一样**。
[点击显示]
`if` ... `elif` ... `else`。
注意看缩进，也要注意冒号。
[点击显示]
这里顺带提一个新装饰器：**`@pure`**。
之前我们学了 `@view` (只读)。
`@pure` 比 `@view` 更纯。它**连读都不读**链上的数据，纯粹就是算数。
比如这个 `check_number` 函数，给它一个 x，它返回一个 y，跟区块链状态完全无关。这就用 `@pure`。
